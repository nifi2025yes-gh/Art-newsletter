다른 PC로 이사 가는 방법 (매뉴얼)
1. 지금 PC에서 할 일

d:\하반기강의\Hermes\museum_newsletter 폴더를 통째로 복사해서 USB에 담습니다.
(꿀팁: 폴더 안의 venv 폴더는 현재 PC 전용이므로 복사할 때 지우고 옮기셔도 됩니다. 용량도 아끼고 오류도 방지할 수 있습니다.)
2. 새로운 PC에서 할 일

USB에 담은 폴더를 새 PC의 원하는 곳에 붙여넣습니다.
새 PC에 **파이썬(Python)**을 설치합니다.
터미널(CMD 또는 PowerShell)을 열고 폴더 안으로 이동한 뒤, 아래 명령어를 순서대로 쳐서 새 PC에 맞는 환경을 뚝딱 만듭니다:
powershell
# 1. 새 PC 전용 가상환경 만들기
python -m venv venv
# 2. 가상환경 켜기
.\venv\Scripts\activate
# 3. 설치 명세서(requirements.txt)를 보고 필요한 부품들 한 번에 설치하기
pip install -r requirements.txt
이제 끝났습니다! 새 PC의 윈도우 작업 스케줄러(Task Scheduler)를 열고, 아까처럼 폴더 안의 run_newsletter.bat 파일이 매주 월요일에 실행되도록 스케줄만 하나 걸어두시면 됩니다. ⏰
